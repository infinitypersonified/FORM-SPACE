# FORM / SPACE — Architecture Studio

An editorial architecture portfolio built with React and Vite. This is a redesigned version focused on spatial imagery, a cinematic opening sequence, editorial serif typography, staggered project compositions, scroll reveals, responsive navigation, and project detail overlays.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Notes
- Project photography and Google Fonts load from external URLs and require an internet connection.
- The studio contact address is a placeholder: `studio@formspace.example`. Replace it before publishing.
- This is a frontend portfolio concept; project descriptions and imagery are illustrative.
